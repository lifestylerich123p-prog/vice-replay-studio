# Episode backlog (ready-made, evergreen)

Written ahead (Nov 18, on Max) so slow days and cheaper plans need no research from scratch.
To use one: copy it to `episodes/<slug>.json` (media paths are relative to `episodes/`), re-check every fact with a
quick search (prices, dates, anything time-sensitive), update `sources`, then `python -m studio.ship episodes/<slug>.json`.
Delete it from the backlog once used. `planned_for` = the plan date it was written for.

| File | Topic | Use when |
|---|---|---|
| gta6-gift-guide.json | GTA 6 gift guide (affiliate) | Tue Nov 24 (launch plan) |
| gta6-vs-gta5.json | GTA 6 vs GTA 5, 6 differences, no spoilers | any slow news day |
