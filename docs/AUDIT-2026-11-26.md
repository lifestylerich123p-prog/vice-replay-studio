# System audit, November 26, 2026 (directive v2.0, section 2)

Scope: the `vice-replay-studio` repo (48 `studio/` modules, 30 test files / 160+ tests), the website repo
(`vicereplay-site`), the scheduled runs and the connected services. Done by the main chat; changes listed at the end.

## What works (keep and reuse)
- **Production**: `studio.ship` → `studio.make_video` (lettering cards on official Rockstar screenshots, Rockstar's
  official map with zoom + numbered pins, free Kokoro TTS, our synthwave music, burned-in captions, 1080x1920),
  segment cache (re-renders only changed cards), Spanish renders (`--es`), check sheet per video.
- **QA**: `studio.vice publish` (rights registry, fact flags, QC: black/frozen frames, loudness, captions vs speech,
  hooks/length rules), quiz-answer check.
- **Duplicate prevention**: `studio/postguard.py` (upload registry on every GitHub branch + the channel's own upload
  list incl. scheduled videos; Instagram caption match + daily count).
- **Publishing**: `studio.youtube_upload` / `studio.youtube_es` (scheduled uploads, playlists, pinned comments later),
  Instagram queue (`studio.instagram_upload --queue`, 4/day cap), TikTok hand-off branch (owner posts).
- **Learning**: `studio.learn` (YouTube Data + Analytics: views, % watched, history snapshots → scorecard),
  `studio.comment_insights`, Windsor read-only (TikTok, Search Console), `studio.ig_stats` (likes only), `studio.flops`.
- **Website**: guide builder, interactive map from `site/map-pins.json` (44 pins), map pictures, IndexNow ping,
  staleness check (`studio.site_stale`: 0 stale).
- **Ops**: `studio.doctor`, `studio.status`, `studio.quota`, map series (`studio.mapseries`), Everygen claim ledger +
  hook (prevents double spending between chats), 8 scheduled runs.

## What needed immediate repair (fixed today)
1. **Approval was an honour-system flag** (`--approve`): nothing tied an upload to a checked package. → New
   `studio/approvals.py` gate (10 conditions, states, content fingerprint, slot/limit checks, reconcile-before-retry,
   auto-pause after 2 failures), wired into `youtube_upload` and `spend`; 11 tests (directive cases 1-5, 7 + more).
2. **Quota math was outdated** (1,600 units per upload): uploads have their own bucket in 2026. → `quota.py`,
   `spend.py` updated (to confirm in Google Cloud Console).
3. **Breaking-news runs could auto-post news Shorts** (worst format, outside the plan). → report-only.
4. **Test isolation bug** in the new module (default-argument path) caught by the tests before any harm. → fixed.
